Pythonのプログラムがエラーを出さずに終了しても、計算結果が正しいとは限りません。この例では `80` の25%引きを計算すると、本来は `60.00` になるはずが `79.75` と表示されます。Pad Code AIのデバッガーで実行を止め、どの行で値がずれたのかを調べましょう。この例はPad Code AI内蔵のPython実行環境で動くため、追加パッケージは不要です。

## 誤った出力を再現する

端末に保存したプロジェクトを開き、`checkout.py` を作ります。以下のコードを入力して保存します。プロジェクトの作り方は、[iPadで最初のPythonプロジェクトを実行する手順](/ja/guides/run-python-on-ipad-pad-code-ai/)を参照してください。

```python
def checkout(subtotal, percent):
    discount = percent / 100
    total = subtotal - discount
    return total

print(f"{checkout(80, 25):.2f}")
```

`checkout.py` を開いて**実行 › アクティブなファイルを実行**を選び、ターミナルに `79.75` が表示されることを確認します。

## ブレークポイントで止めてローカル変数を見る

1. `total = subtotal - discount` の左にある行番号をタップします。左の余白にブレークポイントの印が付きます。
2. 開いているファイルをもう一度実行します。エディターで該当行が強調され、ターミナルに一時停止の状態が表示されます。この時点では、強調された行に処理が到達したところです。
3. **ローカル**で `subtotal = 80`、`percent = 25`、`discount = 0.25` を確認します。`0.25` は割引率を小数にした値ですが、次の行ではこの値を割引額として引いています。
4. **ステップオーバー**をタップして引き算を実行し、`return total` で停止します。ここで `total = 79.75` が表示されます。画面の幅が狭い場合は右に折れた矢印が目印です。変数欄が閉じているときは、デバッグパネル上部の矢印で開けます。

## 計算式を試して修正する

Pad Code AI 3.0では、`checkout` の中で停止している間に式を試せます。**ウォッチ**の**式を追加**欄で `subtotal * percent / 100` を入力して確定すると、現在の変数の値で式が評価され、`20.0` と表示されます。

**続ける**をタップして実行を終えたら、同じ行番号をタップしてブレークポイントを外します。割引額を求める行を `discount = subtotal * percent / 100` に修正し、保存して再実行すると `60.00` が表示されます。続けて呼び出しを `checkout(120, 10)` に変え、結果が `108.00` になることも確認しましょう。

ブレークポイントで止まらない場合は、`checkout.py` が実行対象になっていて、処理される行に印が付いているか確認してください。複数の関数をまたぐ処理で呼び出し元を調べるときは、フレームが複数ある場合にコールスタックを使えます。そのほかの開発機能は[Pad Code AIの製品ページ](/ja/PadCodeAI/)で確認できます。
