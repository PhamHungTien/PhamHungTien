VNIでは数字キーを使ってベトナム語の記号を付けます。英単語を入力するときに`s`や`f`が声調キーとして働かないのが特徴です。[Mac版PHTV](/ja/PHTV/)でVNIとTelexを切り替えても、出力するUnicodeの文字は同じです。

## 声調を付ける数字

| キー | 声調  | 入力例 | 結果 |
| ---- | ----- | ------ | ---- |
| `1`  | sắc   | `ba1`  | bá   |
| `2`  | huyền | `ba2`  | bà   |
| `3`  | hỏi   | `ba3`  | bả   |
| `4`  | ngã   | `ba4`  | bã   |
| `5`  | nặng  | `ba5`  | bạ   |

## 字形を変える数字

| キー | 記号               | 入力例           | 結果    |
| ---- | ------------------ | ---------------- | ------- |
| `6`  | サーカムフレックス | `a6`、`e6`、`o6` | â、ê、ô |
| `7`  | ホーン             | `o7`、`u7`       | ơ、ư    |
| `8`  | ブレーヴェ         | `a8`             | ă       |
| `9`  | 横棒               | `d9`             | đ       |

入力アプリが適切な母音に記号を付けます。`e`の直後に数字を押す`Vie65t`と、数字を最後に押す`Viet65`はどちらも**Việt**になります。

## よく使う単語

| 単語   | 入力        | ポイント                     |
| ------ | ----------- | ---------------------------- |
| người  | `ngu7o72i`  | `u7`と`o7`でươ、`2`でhuyền   |
| được   | `d9u7o7c5`  | `d9`でđ、`5`でnặng           |
| trường | `tru7o7ng2` | 文字の後に`2`でhuyềnを付ける |
| khuyến | `khuye6n1`  | `6`でê、`1`でsắc             |
| Nguyễn | `Nguye64n`  | `6`でê、`4`でngã             |
| năm    | `na8m`      | `8`でă                       |

PHTVでは`uo7`も**ươ**になるので、`nguo72i`で少ないキー入力で**người**を入力できます。

## 声調を直す、数字をそのまま入力する

- 声調を置き換えるには別の声調キーを押します。`ba1`に`2`を続けると**bà**になります。
- 声調として処理された数字をそのまま入力したいときは、同じ数字を続けて押します。`a11`は**a1**、`A44`は**A4**になります。
- PHTVの初期設定では、<kbd>Esc</kbd>で語全体を元のキー入力に戻せます。
- 文字と数字の混ざったコードを続けて入力するには、<kbd>Control</kbd> + <kbd>Shift</kbd>で一時的に英語モードに切り替えます。

## VNIとTelexを比較する

| 用途                       | VNI                              | Telex                            |
| -------------------------- | -------------------------------- | -------------------------------- |
| 記号を付けるキー           | 数字列の`1`〜`9`                 | `s`、`f`、`r`、`x`、`j`、`w`など |
| 長いベトナム語の文         | 数字列まで指を伸ばす             | 文字キーの範囲で入力する         |
| 英語とベトナム語が混ざる文 | 多くの英単語をそのまま入力できる | 英単語の自動復元を使う場合がある |
| `A4`のようなコード         | 数字が声調になる場合がある       | 数字はそのまま入力できる         |

各声調に数字を割り当てたい場合や、英単語と交互に入力する場合はVNI、長いベトナム語を文字キーの範囲で入力するならTelexを試します。PHTVのメニューバー、または「設定」の入力方式から切り替えられます。

## 文を入力して練習する

```text
Ho5c ta65p kho6ng bao gio72 la2 muo65n
```

「Học tập không bao giờ là muộn」になります。文字キーで練習したい場合は[Telex入力表](/ja/guides/bang-go-telex-day-du/)を参照してください。
