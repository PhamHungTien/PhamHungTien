VNI 用数字键添加越南语的变音和声调符号。输入普通英语单词时，`s` 和 `f` 等字母键不会被当作声调键。可在 [Mac 版 PHTV](/zh/PHTV/) 中切换 VNI 或 Telex，最终生成的仍然是 Unicode 文字。

## VNI 声调键

| 按键 | 越南语声调 | 输入  | 输出 |
| ---- | ---------- | ----- | ---- |
| `1`  | sắc        | `ba1` | bá   |
| `2`  | huyền      | `ba2` | bà   |
| `3`  | hỏi        | `ba3` | bả   |
| `4`  | ngã        | `ba4` | bã   |
| `5`  | nặng       | `ba5` | bạ   |

## 改变字形的数字键

| 按键 | 效果     | 输入             | 输出    |
| ---- | -------- | ---------------- | ------- |
| `6`  | 加抑扬符 | `a6`、`e6`、`o6` | â、ê、ô |
| `7`  | 加角符   | `o7`、`u7`       | ơ、ư    |
| `8`  | 加短音符 | `a8`             | ă       |
| `9`  | 加横线   | `d9`             | đ       |

输入法会将符号放在合适的元音上。可以在 `e` 后输入数字，如 `Vie65t`，也可以在末尾输入，如 `Viet65`。两者均生成 **Việt**。

## 练习常用词

| 单词   | 输入        | 变化                               |
| ------ | ----------- | ---------------------------------- |
| người  | `ngu7o72i`  | `u7` 和 `o7` 生成 ươ，`2` 加 huyền |
| được   | `d9u7o7c5`  | `d9` 生成 đ，`5` 加 nặng           |
| trường | `tru7o7ng2` | 输入字母后，按 `2` 加 huyền        |
| khuyến | `khuye6n1`  | `6` 生成 ê，`1` 加 sắc             |
| Nguyễn | `Nguye64n`  | `6` 生成 ê，`4` 加 ngã             |
| năm    | `na8m`      | `8` 生成 ă                         |

PHTV 也将 `uo7` 识别为 **ươ**，所以 `nguo72i` 用更少的按键就能得到 **người**。

## 修正声调或输入数字本身

- 按另一个声调数字可以替换已有声调。输入 `ba1`，再按 `2` 得到 **bà**。
- 某个数字被用于标声调后，重复输入它可恢复数字本身。如 `a11` 得到 **a1**，`A44` 得到 **A4**。
- 若沿用 PHTV 的默认恢复键，可按 <kbd>Esc</kbd> 还原整词的原始按键。
- 连续输入字母与数字混合的代码时，可临时切换英语。默认快捷键为 <kbd>Control</kbd> + <kbd>Shift</kbd>。

## 怎样选择 VNI 或 Telex

| 场景             | VNI                    | Telex                                   |
| ---------------- | ---------------------- | --------------------------------------- |
| 输入变音和声调   | 数字键 `1` 到 `9`      | `s`、`f`、`r`、`x`、`j` 和 `w` 等字母键 |
| 输入大段越南语   | 需要伸手按数字行       | 双手可留在字母区                        |
| 英语和越南语混输 | 大部分英语单词照常输入 | 某些英语单词可能要自动恢复              |
| 输入 `A4` 等代码 | 数字可能会被当作声调键 | 数字键照常输入                          |

如果喜欢每个声调对应一个数字键，或经常中途切换英文，可试用 VNI。如果常写成段的越南语，并希望手指留在字母区，可试 Telex。从 PHTV 的**设置 › 输入 › 输入方式**或菜单栏切换。

## 输入一句完整的话

```text
Ho5c ta65p kho6ng bao gio72 la2 muo65n
```

应看到「Học tập không bao giờ là muộn」。如果想用字母键输入相似的内容，可以查看 [Telex 键位表](/zh/guides/bang-go-telex-day-du/)。
