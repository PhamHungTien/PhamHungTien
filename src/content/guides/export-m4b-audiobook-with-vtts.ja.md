EPUBを別のオーディオブックプレーヤーで聴くなら、vTTSで**M4B**に書き出せます。朗読音声とチャプターマーカーが1つのファイルに収まり、対応プレーヤーで聴きたい章へ移動できます。短い文章の音声を一般的なプレーヤーで再生する場合は、MP3やM4Aも使えます。

## 短いEPUBで準備する

自分で作成したEPUBや、音声への変換が許可されているEPUBを用意します。例えば、自分の学習ノートを「要点」と「練習問題」の2章に分けたEPUBにしておくと、書き出し後に章の切り替えを確認しやすくなります。ファイルを**ライブラリ**に読み込み、本を開いて**目次**を確認します。各章をタップし、意図した文章が開くことを確かめます。M4Bで使われる区切りは、vTTSで読み取れた章に基づきます。

書き出す前に、最初の段落を聴いて本の読み上げ言語、声、速度を調整します。固有名詞の読みが違う場合は、原文の表記を確認し、必要に応じて**発音辞書**に登録して試します。EPUBの取り込み方は[vTTSの読書ガイド](/ja/guides/nghe-sach-epub-giong-doc-tieng-viet-voi-vtts/)を参照してください。

## iPhone、iPad、MacでM4Bに書き出す

以下の手順は、iOS・iPadOS 17以降またはmacOS 14以降で動作する現行のApple版が対象です。

1. **ライブラリ**で本の**目次**へ戻り、ツールバーの**オーディオブックを書き出す**を選びます。
2. 章数と形式が **M4B · AAC** であることを確認します。Apple版では、その本に保存した声と速度で全章を書き出します。
3. 必要に応じて**高音質**を選びます。まずは朗読音声だけで試すと、聞き取りやすさを確認できます。**BGM**を加えるときは、音楽で声が聞き取りにくくならないよう音量を調整します。
4. **書き出す**を選び、完了するまでvTTSを開いたままにします。処理が終わったら、ファイルの保存先を選びます。
5. チャプターに対応したプレーヤーで再生します。Macの「ブック」では**ファイル › 読み込む**で`.m4b`を選び、次の章へ移動できるか試します。[Macの「ブック」への読み込み手順](https://support.apple.com/ja-jp/guide/books/ibkseed72068/mac)

## Androidで書き出す章を選ぶ

Android版で書き出し項目が表示される場合は、**ライブラリ**で本のメニューを開き、**音声を書き出す**を選びます。**すべての章**を選ぶか、**開始**と**終了**の章を指定してから**M4B**を選びます。例えば「練習問題」だけ先に出力すれば、短い音声で設定を確認できます。利用できる項目はインストールしているバージョンで確認してください。

## 形式を選び、結果を確認する

| 用途                             | 形式         |
| -------------------------------- | ------------ |
| 章を移動しながら本を聴く         | M4B          |
| 短い文章の音声を渡す             | MP3またはM4A |
| 対応する音声編集ソフトで加工する | WAV          |

書き出したら、章の先頭と切り替わる箇所を聴きます。プレーヤーに章が表示されない場合は、vTTSの目次と、プレーヤーのM4Bチャプター対応を確認してください。音量や読み上げ速度を直したいときは、vTTSで設定を調整して書き出し直せます。

音声の生成は端末上で行われます。完成したファイルを端末に置くか、クラウドフォルダや別のアプリに渡すかは自分で選べます。無料版には書き出しの利用上限があります。**vTTS Premium**は対応ストアでの買い切りで、アプリの書き出し上限が解除されます。残り回数、価格、購入可否はアプリの表示を確認してください。
