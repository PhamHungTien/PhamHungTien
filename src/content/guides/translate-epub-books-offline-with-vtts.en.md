A book in another language can be easier to follow if you listen to a translated copy. [vTTS](/vTTS/) can translate an imported EPUB and put the result in your library as a separate book. Start with a single chapter on Apple devices, or a short text excerpt on Android, so you can check the wording and voice before translating a longer book.

## Check your device and language pair

On iPhone and iPad, translation requires **iOS or iPadOS 18 or later**. On Mac, it requires **macOS 15 or later**. Choose a source and target that your device offers. Translation languages depend on the platform and language pair, while reading voices come with the app. Apple may ask to download language data the first time. On Android, download the needed language data over Wi-Fi.

If you are unsure how a pair will sound, paste a sentence such as “The library opens at nine. Return the book by Friday.” into the text view, then choose **Translate text**. Use the result to check the library’s opening time and the day the book is due. Try English to Japanese if your device offers that pair. A short test makes a wrong source language easier to spot. For help opening an EPUB, see the [vTTS reading guide](/guides/nghe-sach-epub-giong-doc-tieng-viet-voi-vtts/).

## Translate one chapter on iPhone, iPad or Mac

1. In **Library**, open the book details and choose **Translate book**. The translation tool is available once the book's chapters have loaded.
2. Check **Language**. Leave **Detect automatically** selected for clear source text, or choose the source language yourself if a short or mixed-language sample is misidentified. Select the target from the languages offered.
3. For a book with multiple chapters, choose the same chapter in **From** and **To**. Select **Translate**, accept any language-data download and keep vTTS open while it works.
4. The completed translation is saved as a new library book. Choose **Open book**, then check its title and contents. To translate the whole book later, reopen the original and select **All chapters** if you previously narrowed the range.

## Translate a book on Android

1. Open a book and enter its reader. Choose **Translate book** in the toolbar or under **More** if your screen is narrow.
2. Set **From** and **To** to the source and target languages. If the pair is new, tap **Download using Wi-Fi**. Once the required resources are installed, the sheet shows that the pair works offline.
3. Let vTTS translate the book, then review the result and choose the button to save the translated chapters. Open the separate copy from **Library**. For a short trial on Android, start with **Translate text** and paste an excerpt you are allowed to use.

## Check the translated copy before going offline

Play the first paragraph and check the title, numbers and names against the original. On Apple devices, a translated book opens with the target reading language selected. On either platform, check the language shown in the reader and select a matching voice if needed. Try that paragraph again with your device offline after installing the language data.

If a language is unavailable, check the source setting and choose a supported target. If the library is full, a translation needs space for one more book. Keep the original and remove a copy you no longer need, or check the in-app **vTTS Premium** option if you want to keep more books.

Supported translation and speech run on the device. Android uses Google ML Kit, which can send SDK operational data. The [vTTS privacy policy](/vTTS/privacy.html) explains this and the optional sync settings. If you want to use a finished translation in another player, follow the [M4B audiobook export guide](/guides/export-m4b-audiobook-with-vtts/).
