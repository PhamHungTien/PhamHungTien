让编程助手接触整个项目时，可以从一个易于验证的改动开始。这里使用 [Pad Code AI](/zh/PadCodeAI/) 为三项阅读清单添加重置按钮。你将在 iPad 或 iPhone 上限定任务范围、检查智能体修改的文件，并亲手测试结果。

## 准备测试项目并选择服务

使用 [HTML、CSS 和 JavaScript 预览指南](/zh/guides/preview-html-css-javascript-on-ipad/)里的项目，也可以复制自己的小清单来练习。保存并打开预览，选中一项，确认计数为 `1 / 3`。这是改动前的测试基准。

打开**设置 › AI 助手**，选择服务提供方。在应用中使用 Apple 智能需要 iOS 或 iPadOS 26 及更高版本，并在兼容设备上开启此功能。请参阅 [Apple 的设备与地区要求](https://support.apple.com/en-us/121115)。下载模型需要足够的存储空间和内存。规划、编辑和自动模式需要支持工具调用的模型。使用在线服务时，Pad Code AI 会使用你的 API 密钥，并将消息及你授权的上下文发送给该服务。智能体可在任务进行时申请更多项目上下文。请使用练习项目，检查要发送的内容和分享选项，避免把密钥和私人资料放入练习范围。[Pad Code AI 隐私政策](/zh/PadCodeAI/privacy.html)

## 先让助手给出计划

在项目中打开 AI 面板。要了解某个函数如何工作，可以先用**提问**。若需读取多个文件，选择**规划**，让助手检查项目并建议修改步骤。如果找不到模式，请确认项目已打开，并检查所选服务或模型是否支持智能体操作。

在请求中写明可见的结果和要修改的文件，例如：

> 为清单规划一个「重置」按钮。在 index.html 添加按钮，并在 app.js 添加点击处理函数。点击后取消选中三个复选框，将现有计数器更新为 0 / 3。保留当前样式和每个复选框原有的操作方式。使用预览中已支持的浏览器 JavaScript。

检查计划是否沿用 `updateProgress()` 和现有的复选框列表。计划符合要求后，切换到**编辑**，让智能体实现改动。编辑模式允许修改工作区文件。**自动**模式还允许执行受支持的代码。

## 审查差异并测试结果

1. 在 AI 面板中打开**Agent更改**，选择最近一次操作。窄屏上可从 AI 面板的更多菜单寻找入口。**查看更改**会按文件显示新增和删除的行。
2. 检查 `index.html` 是否有按钮，`app.js` 是否有点击监听器。监听器应取消选中原复选框列表，再调用 `updateProgress()`。如果其他文件也被意外修改，应逐项检查。改动超出计划时，可对该条记录选择**撤销操作**，再给出范围更明确的要求。
3. 用**实时 Web 预览**打开 `index.html`，确认初始状态显示 `0 / 3`。选中两项，确认显示 `2 / 3`，再轻点**重置**，确认复选框均清空且计数回到 `0 / 3`。再选中一项，验证原有开关行为。连接键盘时，还可用 Tab 移到按钮，再按 Enter 激活。

智能体会先把改动写入工作区，可事后在记录中审查。因此适合用小示例或项目副本初次练习。若已用 Git 管理项目，提交前可在源代码管理中检查最终差异。当你能解释改动并重复测试，这套流程也可用于稍大一些的修改。
