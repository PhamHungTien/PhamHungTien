Synology NASに保存した写真や文書を外出先から見るには、データを保護できる接続方法を選びます。ここではリモート接続の方法と確認しておく設定、iPhoneまたはiPadの[My NAS Manager](/ja/MyNASManager/)で接続する手順をまとめます。

## NASが接続を受け付けるアドレス

自宅では`192.168.1.10`のようなプライベートIPでSynologyの管理画面DSMを開けます。標準の管理ポートは暗号化なしのHTTPが**5000**、暗号化するHTTPSが**5001**です。`192.168.x.x`はローカルネットワークか、そのネットワークへのプライベートな経路から接続します。[SynologyのDSMログインポータル資料](https://kb.synology.com/en-global/DSM/help/DSM/AdminCenter/system_login_portal_dsm)

## リモート接続の3つの方法

### QuickConnect

QuickConnectではIDと`quickconnect.to/your-name`のようなアドレスを使います。ルーターで手動のポート転送を設定せずに接続方法を検索し、直接接続できないときはSynologyのリレーサーバーを経由する場合があります。

設定が比較的簡単で、固定の公開IPは不要です。リレー経由では大きなファイルの転送が遅くなることがあり、QuickConnect IDを入力できないサードパーティ製アプリもあります。

### DDNSとポート転送

DDNS（Dynamic DNS）は、`your-nas.synology.me`のようなホスト名と変動する公開IPアドレスを対応させます。DSMの「コントロール パネル → 外部アクセス → DDNS」で設定できます。

ポート転送を使うと、ルーターが選んだ公開ポートへの接続をNASへ渡します。HTTPS用の5001を転送すると、DSMへの接続やログイン試行をインターネットから受け付けます。直接接続は回線の速度を利用できますが、公開する場合はDSMを更新し、下記の保護を設定します。契約先がCGNATを使っている場合は通常のポート転送が動作しないことがあります。ルーターのWANと公開IPを比較し、不明なら契約先に確認します。

### VPN

VPNを使うと、DSMのポートを公開せず、NASへプライベートな経路を作れます。

- **Tailscale**はNASとApple端末にインストールし、NASのTailscaleアドレスで接続します。自宅のLAN側のIPに接続するにはサブネットルーティングが必要です。DSMのポートを手動で公開せず、CGNAT環境でも使える場合があります。
- **Synology VPN Server**はOpenVPNなどに対応します。選んだVPN方式に合わせてネットワークを設定し、必要な場合はVPNのポートを転送します。
- ルーターによっては**WireGuard**や**OpenVPN**で自宅のネットワークへ接続できます。

| 用途                                            | 選択肢                               |
| ----------------------------------------------- | ------------------------------------ |
| ときどき写真や文書を開く                        | QuickConnectと対応するSynologyアプリ |
| NASの管理、ファイル転送、サードパーティ製アプリ | VPNまたはTailscale                   |
| VPNを使わない直接アクセス                       | DDNSとアクセスを制限したHTTPS転送    |

NASに接続できるユーザーと端末をアクセスルールで絞ります。[TailscaleのSynology公式ガイド](https://tailscale.com/docs/integrations/synology)

## 接続を許可する前にNASを保護する

1. 代わりの管理者アカウントが使えることを確認してから、標準の`admin`を無効にします。
2. 長く、使い回していないパスワードを選びます。
3. 管理者アカウントで2段階認証を有効にします。
4. DSMの自動ブロックを有効にして、繰り返し失敗するログインを制限します。
5. HTTPSを使います。公開ホスト名では、DSMの「コントロール パネル → セキュリティ → 証明書」で、Let's Encryptなど信頼できる認証局の証明書を設定します。
6. 公開するポートは必要なものに絞ります。SSHは直接公開せず、ルーターの自動ポート割り当てやUPnPを確認します。
7. DSMとインストール済みのパッケージを更新します。
8. 別の場所にバックアップを保管します。RAIDは一部のディスク障害から保護します。対応している場合はスナップショットも使い、外部ドライブやバックアップサービスに別のコピーを作ります。

[SynologyのNAS保護のガイド](https://kb.synology.com/en-us/DSM/tutorial/How_to_add_extra_security_to_your_Synology_NAS)

## My NAS Managerで接続する

My NAS Managerは、iPhoneとiPadからDSM 7を実行するSynology NASを管理します。リソースの監視、ファイルの参照、パッケージやSSHサービスの管理ができます。

- **NAS IP / DNS**には、自宅のローカルIP、VPN経由で届くアドレス、NASのTailscaleアドレス、設定済みのDDNSホスト名のいずれかを指定します。
- **DSMポート**はHTTPSの`5001`または設定したHTTPSポートです。暗号化されないHTTPの標準は`5000`です。
- **DSMのユーザー名とパスワード**はNAS上のアカウントを指定します。必要な権限だけを持つ専用アカウントを使います。

2段階認証を利用する場合は2FAを有効にして、求められたときにワンタイムコードを入力します。サインインを保持する設定はDSMセッションをキーチェーンに保存します。外出先からは先にVPNまたはTailscaleに接続し、サブネット経由で接続する設定がなければTailscaleのNASアドレスを使います。

### 接続できないとき

| 問題                      | 確認する項目                                            |
| ------------------------- | ------------------------------------------------------- |
| DSMに接続できない         | アドレス、ポート、VPN、HTTPS設定、NASのファイアウォール |
| DSMがサインインを拒否する | ユーザー名、パスワード、2FAコード、自動ブロック         |
| 証明書が信頼されない      | DSMのホスト名、証明書の有効期限とチェーン               |
| NASアドレスが無効         | 余分な空白、入力ミス、ポートの書式                      |

ログインに何度も失敗した場合は、DSMのセキュリティ設定でブロックリストを確認します。

## 接続後にできる操作

CPU、メモリ、温度、ネットワーク、ドライブ、RAIDを確認できます。端末からのアップロード、「ファイル」へのダウンロード、共有リンクの発行や、Download Stationなどのパッケージの開始・停止も可能です。SSHサービスはオン・オフとポート変更ができ、診断画面で`ls`、`df -h`、`top`、`uptime`などの項目を確認できます。SSHが不要になったらオフにします。[My NAS ManagerをApp Storeで見る](https://apps.apple.com/app/id6780180564)
