Telexは文字キーでベトナム語の補助記号や声調を付ける方式です。元の文字を入力してから、字形や声調を変えるキーを押します。以下は[Mac版PHTV](/ja/PHTV/)の例です。基本の組み合わせは多くのTelex入力アプリで使えます。

## â、ă、ê、ô、ơ、ư、đを入力する

| キー  | 文字 | 入力例   | 結果 |
| ----- | ---- | -------- | ---- |
| `aa`  | â    | `caan`   | cân  |
| `aw`  | ă    | `awn`    | ăn   |
| `ee`  | ê    | `ddeem`  | đêm  |
| `oo`  | ô    | `coo`    | cô   |
| `ow`  | ơ    | `mow`    | mơ   |
| `uw`  | ư    | `tuw`    | tư   |
| `uow` | ươ   | `nuowcs` | nước |
| `dd`  | đ    | `ddi`    | đi   |

PHTVの標準Telexでは、`w`だけで`ư`を入力でき、`nhwng`は**nhưng**になります。`[`は`ơ`、`]`は`ư`です。Simple Telexではこれらのショートカットの動作が異なります。

## 声調を入力する

| キー | 声調           | 入力例 | 結果 |
| ---- | -------------- | ------ | ---- |
| `s`  | sắc            | `bas`  | bá   |
| `f`  | huyền          | `baf`  | bà   |
| `r`  | hỏi            | `bar`  | bả   |
| `x`  | ngã            | `bax`  | bã   |
| `j`  | nặng           | `baj`  | bạ   |
| `z`  | 声調を取り消す | `basz` | ba   |

声調キーは、末尾の子音の前でも音節を入力し終えた後でも押せます。`vieejt`と`vieetj`はどちらも**việt**になります。入力アプリが対応する母音に記号を置きます。

## よく使う語を練習する

| 単語   | たたくキー | ポイント                  |
| ------ | ---------- | ------------------------- |
| người  | `nguowif`  | `uow`でươ、`f`でhuyền     |
| được   | `dduwowcj` | `dd`でđ、`j`でnặng        |
| trường | `truowngf` | `f`でơにhuyềnを付ける     |
| khuyến | `khuyeens` | `ee`でê、`s`でsắc         |
| Nguyễn | `Nguyeexn` | `ee`でê、`x`でngã         |
| thuở   | `thuowr`   | `w`で母音を変え、`r`でhỏi |
| quốc   | `quoocs`   | `oo`でô、`s`でsắc         |

## 記号を直す、元の入力に戻す

- 声調を変えるには別の声調キーを押します。`bas`の後に`f`を押すと**bà**になります。
- 声調を外すには`z`を押します。`basz`は**ba**になります。
- キーを繰り返すと、変換せずに入力した文字を復元できます。`ass`は**as**、`aaa`は**aa**になります。
- PHTVで入力中の語をキー入力どおりに戻す初期設定は<kbd>Esc</kbd>です。他のアプリと重なる場合は「設定」内のショートカットを変更できます。

## 声調記号を置く位置を選ぶ

**oa**、**oe**、**uy**のような母音の組み合わせには、**hòa、khỏe、thúy**と**hoà、khoẻ、thuý**のように2つの表記があります。キー入力は共通です。PHTVの「設定」から入力設定を開き、現代正書法（Modern Orthography）の設定を原稿に合わせてください。

## 子音のショートカット

入力設定でQuick Telexを有効にすると、子音を2回押して子音の組み合わせを入力できます。

| 入力 | 結果 | 入力 | 結果 |
| ---- | ---- | ---- | ---- |
| `cc` | ch   | `nn` | ng   |
| `gg` | gi   | `pp` | ph   |
| `kk` | kh   | `qq` | qu   |
| `tt` | th   |      |      |

頭子音と末尾子音の省略入力もあります。頭子音では`f`、`j`、`w`が`ph`、`gi`、`qu`に、末尾では`g`、`h`、`k`が`ng`、`nh`、`ch`に変わります。初期設定ではオフなので、どの設定が入力に影響したか分かるように一つずつ試します。

## 同じアプリでベトナム語と英語を使う

| PHTVの方式     | `w`だけでư | `[`と`]`でơとư |
| -------------- | ---------- | -------------- |
| Telex          | 可         | 可             |
| Simple Telex 1 | 不可       | 不可           |
| Simple Telex 2 | 可         | 不可           |

どの方式でも`aw`、`ow`、`uw`は使えます。コードなどで単独の`w`や角括弧を頻繁に使うなら、Simple Telex 1を試してください。PHTVは認識した英単語をSpaceで復元できます。長い英語の文章は初期設定の<kbd>Control</kbd> + <kbd>Shift</kbd>で切り替えるか、アプリ別に入力方式を設定します。

## 文を入力して練習する

```text
Dduwowngf ddi khoong khos vif ngawn soong cachs nuis
Truowngf Vieejt Nam ddepj nhaast nawm nay
```

「Đường đi không khó vì ngăn sông cách núi」と「Trường Việt Nam đẹp nhất năm nay」になります。数字キーで入力したい場合は[VNI入力表](/ja/guides/cach-go-vni-telex-hay-vni/)を試してください。
