古い文書に「TiÕng ViÖt」や「Tieáng Vieät」と表示される場合、元の文字コードやフォントに合わせて保存されている可能性があります。コピーを作り、元の文字コードを確認してからUnicodeに変換しましょう。ここでは[Mac版PHTV](/ja/PHTV/)の文字コード変換機能を使います。

## ベトナム語の文字コードの違い

文字コードは数値を文字に対応させます。以前の規格には、ある規格で記号付き文字に当たる数値を、別の規格では無関係な文字に割り当てるものがあります。元の文字コードやフォントの情報がないと、新しいエディターで開いた際に文字化けすることがあります。

| 文字コード                 | 見分ける手がかり                                      | 主な用途                             |
| -------------------------- | ----------------------------------------------------- | ------------------------------------ |
| **Unicodeの合成済み文字**  | ệなどを1つのコードポイントで表せる                    | 現在のWeb、アプリ、文書              |
| **Unicodeの分解表現**      | 基本文字と結合記号が別のコードポイント                | システム間のコピー、一部のファイル名 |
| **TCVN3（ABC）**           | `.VnTime`など`.Vn`で始まるフォント                    | ベトナムの古い行政や教育の文書       |
| **VNI Windows**            | `VNI-Times`などのフォントや「Tieáng Vieät」などの表示 | 旧来の文書、デザインデータ           |
| **Windows-1258（CP1258）** | 一部に結合記号を使うWindowsの文字コード               | 旧来のWindowsアプリ、出力データ      |

新規文書にはUnicodeを使います。VNI Windowsという文字コードと、VNIという入力方式は別々に選択できます。VNI方式で入力しながら、文字コードをUnicodeに設定できます。

## 記号が消えたり文字化けしたりする理由

1. `.VnTime`などの旧来のフォントに依存する文書を、別のフォントで表示している。
2. エディターはUnicode向けなのに、入力アプリではTCVN3やVNI Windowsを選んでいる。
3. 同じ見た目でもUnicodeのコードポイント列が異なり、正規化しない検索やファイル名の比較で一致しない。

## PHTVで文字コードを設定する

入力設定の文字コードから、通常は**Unicode**を選択します。同じ文字コードの古い文書を編集するときは、TCVN3またはVNI Windowsを選びます。よく使う旧式アプリがあれば、PHTVのアプリ別設定で文字コードを記憶できます。

## 古い文章をUnicodeへ変換する

1. 文書のコピーを作り、問題のある短い部分を<kbd>⌘</kbd> + <kbd>C</kbd>でコピーします。
2. PHTVのツールメニューまたはシステム設定パネルから、文字コード変換を開きます。
3. 変換元の文字コードと、変換先の**Unicode**を選んでクリップボードの内容を変換します。
4. <kbd>⌘</kbd> + <kbd>V</kbd>で貼り付け、Times New Roman、Arial、HelveticaなどのUnicode対応フォントを指定します。
5. 残りを変換する前に、記号付きの語や大文字と小文字を確認します。「TiÕng ViÖt」ならTCVN3、「Tieáng Vieät」ならVNI Windowsが手がかりです。

コピーだけで文字を復元できない場合は、文書を元の文字コードやフォントで開き直してから試します。

## 合成済み文字と分解表現

**ệ**は`U+1EC7`で表せます。また、`e`に下の点とサーカムフレックスを結合しても同じように見えます。コードポイント列の長さやバイナリ表現が異なるため、そのまま比較すると一致しないことがあります。プログラムで比較する場合はNFCなど同じUnicode形式に正規化します。[Unicode正規化仕様](https://www.unicode.org/reports/tr15/)

Unicodeの文書で入力中だけ記号が消える場合は、[Macでベトナム語入力を直す手順](/ja/guides/sua-loi-go-tieng-viet-tren-mac/)を確認してください。
