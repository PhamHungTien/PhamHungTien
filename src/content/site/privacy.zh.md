本政策适用于 **phamhungtien.com**，包括主页、应用页面、指南和讨论区。每款应用均有单独的隐私政策，可从对应产品页面进入。

## 概要

- 浏览网站无需登录。在讨论区发帖需要 Google 账户。
- **指南**中的文章展示 **Google AdSense** 广告。Google 和其合作伙伴可能使用 Cookie 投放广告。主页和应用页面不展示广告。

## 浏览器中保存的数据

- **浅色或深色外观。** 你选择的外观使用 `theme` 键保存在浏览器的本地存储中，不离开设备。
- **最新下载链接。** PHTV 页面向 GitHub 请求发布列表，以便显示正确的下载按钮。返回的数据缓存在本地存储中，避免每次访问都请求。

你可以通过清除浏览器中的网站数据，随时移除这些数据。

## Google AdSense 广告

指南中的文章展示 **Google AdSense** 提供的广告：

- Google 等第三方供应商使用 Cookie，根据你以往访问本网站或其他网站的情况投放广告。
- Google 使用广告 Cookie，让 Google 及其合作伙伴能根据你访问本网站或互联网上其他网站的情况向你投放广告。
- 可在 [Google 广告设置](https://adssettings.google.com)中停用个性化广告，并在 [www.aboutads.info](https://www.aboutads.info/choices/)上选择停用其他第三方供应商的 Cookie。
- 如果 Google 显示同意提示或隐私选项链接，可通过它查看或更改广告偏好。
- 了解 Google 如何使用来自其服务合作网站的数据。[Google 合作网站数据说明](https://policies.google.com/technologies/partner-sites)

## 讨论区

各应用页面均有讨论区，用于提问、报告问题和反馈。讨论区由 Google 的 **Firebase** 提供支持：

- 你使用 Google 账户登录。Firebase Authentication 会收到显示名称、电子邮箱地址和账户标识符。
- Cloud Firestore 保存帖子或回复、显示名称、账户标识符和发布时间。**帖子与回复是公开的。** 电子邮箱地址用于登录，不会包含在新发表的帖子中。
- 可使用提供的删除功能移除自己发布的内容。管理员可能移除违反规则的内容。对于较早的帖子或无法自行移除的信息，请联系下方邮箱。
- Firebase 可能在浏览器中保留登录状态。[Google 隐私政策](https://policies.google.com/privacy)

仅在打开讨论区标签后才加载 Firebase。

## 嵌入内容和第三方服务

- **YouTube。** 教程在播放前显示预览图。网站会尽可能提供本地副本，也可能从 YouTube 获取预览图。点击播放时，播放器从 YouTube 的增强隐私域名加载。
- **GitHub。** PHTV 页面使用 GitHub 的公开 API 查询最新下载。
- **网站托管。** GitHub Pages 托管网站，Cloudflare 通过其网络分发网站内容。它们可能会处理 IP 地址、浏览器详情和访问时间等请求信息，用于提供、运营和保护网站。
- **捐赠。** 捐赠按钮可打开 PayPal 或显示银行转账二维码。网站不会接收或存储你的支付信息。

这些服务按各自的隐私政策处理数据。

## 儿童

本网站不面向 13 岁以下儿童，也不会在知情情况下收集其数据。

## 变更

如果网站处理数据的方式发生变化，本政策将更新，页面顶部的日期也将相应变化。
