## 1\. Aceptación de las condiciones

Al descargar, instalar o usar Pad Code AI («la app»), aceptas estas condiciones de uso. Si no las aceptas, no uses la app.

## 2\. Descripción del servicio

Pad Code AI es un editor de código y entorno de desarrollo para iPad y iPhone. Permite escribir, editar, ejecutar y gestionar código fuente. Incluye entornos de ejecución en el dispositivo, una terminal, Git, SSH y SFTP en las versiones compatibles y un asistente de programación con IA opcional.

## Funciones de pago opcionales

La edición básica, la ejecución local compatible, la vista previa web, Git, la importación, la exportación y el reemplazo en un solo archivo están disponibles sin comprar. Donde esté disponible, Pad Code AI Pro puede ofrecerse como compra única o como suscripción mensual o anual con renovación automática. El App Store muestra las funciones disponibles, el precio, el período de facturación y cualquier período de prueba antes de confirmar. Puedes gestionar la suscripción en los ajustes de tu cuenta de Apple y restaurar las compras elegibles en la app con la cuenta que usaste para realizarlas. Las compras reembolsadas o revocadas dejan de conceder el derecho de acceso adquirido. El acceso otorgado o comprado anteriormente sigue sujeto a las condiciones bajo las que se concedió. Los cargos de proveedores de IA externos son independientes. [Suscripciones y facturación de Apple](https://support.apple.com/billing)

## 3\. Contenido del usuario

Conservas todos los derechos sobre el código, archivos y proyectos que crees, edites, abras, clones o ejecutes en la app. No reclamamos la titularidad de tu contenido.

Tú eres la única persona responsable del código que escribas, ejecutes, clones o subas con la app.

## 4\. Ejecución en el dispositivo

Los programas se ejecutan en un entorno aislado del dispositivo para programar, aprender y probar. El entorno no ofrece acceso completo al sistema. Ejecutar código Python puede descargar paquetes y dependencias adicionales desde servicios de paquetes. El contenido de la vista previa web puede acceder a servicios remotos a los que haga referencia tu código. El código fuente no se carga en un servidor de compilación ni de ejecución. Se limitan el tiempo de ejecución, la memoria y la salida para mantener la app operativa.

## 5\. Asistente de IA

El asistente opcional puede usar un modelo compatible en el dispositivo o un proveedor externo que configures con tu propia clave de API, según el dispositivo y la disponibilidad regional del App Store. Si usas un proveedor externo:

- Su uso también se rige por las condiciones y la política de privacidad de ese proveedor.
- Eres responsable de tu clave de API y de los cargos por uso que te facture el proveedor.

Las sugerencias generadas por IA se proporcionan tal cual y deben revisarse antes de su uso. No nos hacemos responsables de la exactitud ni de la idoneidad del código generado por IA.

## 6\. Git y funciones de red

Los comandos de Git clone, fetch, pull y push se comunican con el alojamiento compatible de repositorios HTTPS que elijas, incluidos alojamientos distintos de GitHub. La autenticación puede requerir un token de acceso para ese alojamiento. Eres responsable de:

- Los repositorios que clones y el código que subas.
- Proteger tus tokens de acceso a repositorios.
- Cumplir las condiciones de servicio de cualquier plataforma externa que uses.

Conéctate mediante SSH o SFTP solo a sistemas a los que estés autorizado a acceder. Eres responsable de proteger tus credenciales, verificar la identidad del servidor y revisar los comandos, transferencias y ediciones en él. Se aplican las condiciones del operador del servidor.

## 7\. Componentes de código abierto

La app incluye software de código abierto como LLVM/Clang, CPython (Pyodide), Ruby, PHP, Lua y TypeScript. Sus licencias se muestran en Ajustes › Acerca de › Licencias de código abierto. La app es software propietario.
