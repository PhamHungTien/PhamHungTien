## 2. 服务说明

Pad Code AI 是适用于 iPad 和 iPhone 的代码编辑器和 IDE。你可编写、编辑、运行及管理源代码，并使用内置的本地运行环境、终端和 Git。受支持的版本提供 SSH 和 SFTP，还可选择使用 AI 编程助手。

## 可选付费功能

## 4. 在设备上执行代码

程序在设备沙盒中运行，用于编程、学习和测试。沙盒无法提供完整的系统访问权限。运行 Python 代码时可能从包服务下载额外的包及其依赖。网页预览可能连接代码引用的远程服务。你的源代码不会上传到编译或执行服务器。执行时间、内存和输出均受限制，以保持本应用响应。

## 5. AI 助手

可选 AI 助手可使用受支持的设备端模型，或你用自有 API 密钥配置的第三方服务，具体取决于设备和 App Store 地区可用性。若使用第三方服务：

- 你的使用同时适用该提供方的条款和隐私政策。
- 你负责保管自己的 API 密钥，并承担提供方收取的使用费。

AI 生成的建议按现状提供，使用前应核对。我们不对 AI 生成代码的准确性或适用性负责。

## 6. Git 和联网功能

Git 的 clone、fetch、pull 和 push 与你选定的兼容 HTTPS 仓库托管方通信，包括 GitHub 以外的托管方。认证可能需要访问令牌。你应对下列事项负责：

- 选择克隆的仓库和推送的代码。
- 保护仓库访问令牌。
- 遵守所用第三方平台的服务条款。

仅通过 SSH 或 SFTP 连接获授权访问的系统。你负责保护登录信息、核验服务器身份，并审查在服务器上提交的命令、文件传输和编辑。适用服务器运营方的条款。
