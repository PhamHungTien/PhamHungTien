## 1. 規約への同意

Pad Code AI（以下「本アプリ」）をダウンロード、インストール、または使用すると、本利用規約に同意したことになります。同意しない場合は本アプリを使用しないでください。

## 2. サービスの説明

Pad Code AIはiPadとiPhone向けのコードエディター・統合開発環境です。ソースコードの作成、編集、実行、管理を行えます。端末上で動作する言語の実行環境、ターミナル、Git、対応バージョンでのSSHとSFTP、オプションのAIコーディングアシスタントを備えています。

## オプションの有料機能

基本の編集、対応するローカルコードの実行、Webプレビュー、Git、読み込みと書き出し、単一ファイル内の置換は、購入なしで利用できます。提供される場合、Pad Code AI Proは買い切り、自動更新される月額または年額のサブスクリプションとして提供されることがあります。確認前に、利用できる機能、価格、請求期間、トライアルの有無をApp Storeに表示します。サブスクリプションはApple Accountの設定で管理でき、対象の購入は購入時のApple Accountを使ってアプリで復元できます。返金または取り消しがあった購入による利用資格は失効します。以前に付与または購入された利用資格には、当時の条件が適用されます。第三者のAIサービス料金は別途かかります。[Appleのサブスクリプションと請求](https://support.apple.com/billing)

## 4. 端末上でのコード実行

プログラムは、コーディング、学習、テストのため、端末上のサンドボックスで実行されます。サンドボックスからシステム全体にアクセスすることはできません。Pythonコードの実行時に、パッケージサービスから追加のパッケージや依存関係をダウンロードすることがあります。Webプレビューのコンテンツは、コード内で参照している外部サービスに接続する場合があります。ソースコードをコンパイルや実行用のサーバーにアップロードすることはありません。アプリの応答性を保つため、実行時間、メモリ、出力には上限があります。

- プロバイダの規約とプライバシーポリシーにも従うものとします。

## 6. Gitとネットワーク機能

Gitのclone、fetch、pull、pushは、GitHubを含む、選択した対応HTTPSリポジトリホストと通信します。認証にはホスト用のアクセストークンが必要な場合があります。以下は利用者の責任です。

- クローンするリポジトリとpushするコード。
- リポジトリのアクセストークンの保護。
- 利用する第三者プラットフォームの規約の遵守。

SSHやSFTPでは、アクセスを許可されたシステムにのみ接続してください。サインイン情報の保護、サーバーの身元の確認、コマンド、ファイル転送、サーバー上での編集の確認は利用者の責任です。サーバー運営者の規約が適用されます。
