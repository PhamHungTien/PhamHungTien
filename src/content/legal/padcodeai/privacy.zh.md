## 概述

Pad Code AI 是适用于 iPad 和 iPhone 的本地优先代码编辑器和 IDE。本政策说明哪些内容保留在设备上，以及所用功能会在什么情况下与第三方服务通信。

## 开发者收集的数据

- 本应用不要求注册由开发者管理的账户。
- 应用不包含第三方分析、广告或跟踪框架，也不会将使用情况遥测数据发送到开发者运营的服务器。
- 我们不运营接收项目或 AI 对话的服务器。如你主动发送支持邮件，我们会收到你选择写入邮件的信息。
- Apple 可根据设备设置和自己的政策处理 App Store 及诊断信息。下文所述的联网服务可能收到提供相应功能所需的信息。

## 代码、文件与本地执行

项目和源文件保存在应用存储空间，或保存在你从「文件」应用打开的文件夹中。使用分享或联网功能时，文件会按照所选功能处理。你在「文件」中选择的存储提供方可能依据自己的政策同步相应文件夹。

受支持的程序在设备沙盒内编译或解释执行。应用不会将源代码上传到编译或执行服务器。运行环境的访问受到限制，无权完整访问设备或系统。

### Python 依赖包

运行引用额外依赖包的 Python 代码时，应用可能从 Pyodide 的包分发 CDN 或 Python Package Index（PyPI）下载所需包及其依赖。仅使用标准库的程序无需下载这些包。包服务会收到请求的包名、版本和 IP 地址等普通连接信息。应用在设备上分析导入语句，无需为识别所需包向这些服务上传源文件。下载需要联网，适用包服务自身的政策。

### 网页预览

网页预览使用 WebKit 显示你选择的 HTML、CSS 和浏览器 JavaScript。预览内容可能请求远程图片、脚本和其他资源，也可能与代码引用的服务通信。这些服务会收到内容发送的数据。本地编译和执行时，部分预览和包操作仍可能联网。

## 可选的 AI 助手

你可在设置中选择是否使用 AI 及其运行方式：

- **受支持的设备端模型。** 提示词和代码在你的设备上处理。可以从模型托管方下载受支持的模型，也可导入你选择的模型文件。托管方收到模型请求和普通连接信息。此模式下的聊天消息和工作区内容在本地处理。
- **可选的第三方提供方。** 当你发送消息时，提示词会从设备直接发送到你配置的提供方或兼容端点，具体取决于该服务在 App Store 所在地区的可用性。当前文件内容和项目文件名按你启用的共享选项纳入请求。如果你允许智能体任务访问工作区，该任务的对话也可能包含相关文件及工具结果。

应用在与远程提供方共享前会征求同意。你可在设置中更改共享选项或撤销权限。远程 AI 数据发送至你选定的提供方，不经过开发者的 AI 服务器。该提供方的隐私政策、保留规则和条款适用。如果使用可选的 OpenRouter 登录，OpenRouter 会处理认证并向应用发放 API 密钥。

## Git、GitHub 和凭据

Git 功能直接与所选的兼容 HTTPS 仓库托管服务通信，包括 GitHub 以外的托管方。clone、fetch 和 pull 会请求仓库数据，push 会上传你选择发布的提交和文件。认证时会发送仓库托管方要求的凭据。托管方会收到普通连接信息，并按自己的政策处理。如果在设置中登录 GitHub，GitHub 会处理授权，应用使用访问令牌列出和打开你的账户可访问的仓库。

API 密钥和已保存的 Git 访问令牌存放在 iOS 钥匙串中。应用只将其用于需要相关凭据的已配置服务。请保护仓库网址和凭据，仅连接可信服务。

## 通过 SSH 和 SFTP 访问远程服务器

连接你配置的服务器时，设备直接向该服务器发送认证消息、终端输入以及你选择读写的文件。保存的服务器地址、用户名和主机指纹保存在设备上。保存的密码、私钥和密钥口令存放在设备钥匙串中。私钥在本机用于认证。断线时，应用可在本地暂存已保存的远程文件修改，并在服务器恢复连接后上传。远程系统可能根据自己的政策记录访问、命令和文件。

## App Store 购买

可选的 Premium 购买使用 Apple StoreKit。Apple 处理付款和恢复购买。应用检查经验证的购买权限以解锁高级工具，也会检查 App Store 店面以确定地区可用性。StoreKit 可能在用户未主动发起购买时与 Apple 通信，以获取价格或刷新购买和店面信息。你的支付卡信息不会发送给开发者。

## 其他网络功能

访问支持、社区、视频或 App Store 链接时，浏览器或相关应用会联系目标服务。分享或导出项目只会向指定位置发送内容。相应的服务和接收方采用各自的隐私规则。

## 儿童隐私

应用无需个人资料，也不含面向儿童的广告或跟踪框架。上述本地存储和可选服务规则适用于所有用户。第三方服务可能设有自己的年龄要求和政策。
