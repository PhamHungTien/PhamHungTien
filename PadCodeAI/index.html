Features

  • Vibe Coding

    Describe the app or change you want. The AI plans it, writes the files and runs the code to check its work. Pick Ask, Plan, Edit or Auto, and review or undo every change as a diff.

  • AI your way

    Apple Intelligence runs privately on device, agent tasks included. Or bring your own key for a third-party provider, or download open models such as Qwen and Gemma to use offline.

  • Bundled compilers

    C, C++, Python, JavaScript, TypeScript, Ruby, PHP, Lua and SQLite run offline with input, arguments and project files. Python adds breakpoints, matplotlib plots and packages such as NumPy and pandas.

  • Previews and LaTeX

    Preview HTML, CSS, JavaScript, Markdown and SVG. Typeset LaTeX with math, tables and figures, and print or save any preview as PDF.

  • SSH, SFTP and a shell

    A full-color SSH terminal that runs vim, htop and tmux, plus SFTP to browse and edit server files. The local shell has ls, cd, grep and pipes, with python3, node, gcc and npm.

  • A real editor

    Syntax highlighting, completion, go to definition, find references, rename, project-wide search and replace, folding, snippets and a split editor.

  • Git built in

    Clone over HTTPS from GitHub, GitLab and Bitbucket. Review diffs, commit, branch, stash, push and pull; sign in to GitHub to open private repositories too.

  • Free where it counts

    The AI agent and Vibe Coding are free. The split editor and project-wide replace have a daily free allowance; a one-time purchase removes the limit, with no subscription.
