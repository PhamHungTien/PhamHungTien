Features

  • 01

    Visual Run Configuration

    Choose entry files, arguments, environment variables, working directories, and timeouts; jump to the exact error location from diagnostics.

  • 02

    Web preview in 2.0

    Preview HTML, CSS and browser JavaScript with WebKit. Swift/SwiftUI, Metal and native OpenGL graphical previews are not supported.

  • 03

    One-time Premium from 2.0

    Premium unlocks split editing and bulk workspace replacement without a subscription. Editing, supported runners, web preview, Git and export stay free. The App Store shows your local price before confirmation.

  • 04

    Real compilers, fully offline

    Clang for C/C++, CPython, Ruby, PHP, Lua, TypeScript, a Node.js-style JavaScript runtime, and SQLite ship inside the app. No server, and no simulated output.

  • 05

    Interactive terminal

    input(), scanf, cin, and io.read wait for you just like on a computer, and ^D ends input. Pass arguments, read and write project files, and stop any program instantly.

  • 06

    Errors on the exact line

    Compiler errors and exceptions are marked on the failing line in the editor.

  • 07

    An editor for touch and keyboard

    Highlighting for 43 languages, a coding keyboard bar, folding, a minimap, outlines, workspace search, in-file replacement, and a full menu bar with keyboard shortcuts.

  • 08

    Git and projects

    Open folders from the Files app, clone from GitHub, review changes, commit, push, stash, and export projects as ZIP.

  • 09

    An AI assistant you control

    Explain, refactor, write tests, and fix bugs in one tap. Changes appear as a diff to review before applying. Use the on-device model or your own API key; nothing is sent without your permission.
