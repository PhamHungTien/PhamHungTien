功能

  • 在设备上处理输入

    输入引擎在 Mac 上处理文字。打开 GIF 或贴纸选择器、在其中搜索或检查更新时，PHTV 会联网。GIF 和贴纸来自 Klipy。

  • 原生菜单栏应用

    PHTV 使用 Swift 为 macOS 编写。可从菜单栏打开设置、更改输入方式，以及在越南语和英语之间切换。

  • 智能输入

    提供拼写检查、快速 Telex、自动恢复英文、宏和双语输入细节设置。

  • Telex、VNI 和简易 Telex

    选择熟悉的输入方式。按 Control + Shift 或使用菜单栏，在越南语和英语之间切换。

  • PHTV 选择器与剪贴板

    插入表情符号、贴纸和 GIF，或找回剪贴板历史记录中的内容。

  • PHTV Keyboard 版

    PHTV Keyboard 是面向 App Store 的版本。沙盒中的 Mac 版支持快捷短语、剪贴板历史记录和表情符号；iPhone 和 iPad 版支持词语建议、滑动输入和打字竞速。

    关闭 macOS 的自动纠正功能。

  2. 2

    按 PHTV 的设置提示授予一项权限。macOS 27.3 及以上版本请查找 System & App Protection Override，27.0–27.2 请查找 Device Control and Data Access，较早版本请查找「辅助功能」。

    按 Control + Shift 在越南语与英语之间切换。

常见问题

PHTV 支持哪些 macOS 版本？

支持 macOS 14 Sonoma 及更高版本，分别提供 Apple 芯片和 Intel 芯片版本。

怎样安装和更新 PHTV 最方便？

使用 Homebrew：用 brew install --cask phtv 安装，用 brew upgrade --cask --greedy phtv 更新，用 brew uninstall --cask phtv 卸载。手动下载时，请选择对应 Apple 芯片或 Intel 芯片的版本。

如何在越南语和英语之间切换？

按已配置的快捷键（默认 Control + Shift），或通过菜单栏图标选择语言。

我该选哪种输入方式？

Telex 最常用（ow = ơ、uw = ư、aa = â）。VNI 用数字 1–9 添加符号。简易 Telex 提供更简洁的 Telex 输入方式。

PHTV 会把我输入的文字发送到网上吗？

输入内容在设备上处理。PHTV 在检查更新以及使用选择器加载 Klipy 的 GIF 和贴纸时联网。参加打字竞速时，PHTV Keyboard 可以连接 Game Center。

为什么 PHTV 需要系统权限？

这项权限让 PHTV 接收按键，并在当前输入位置插入已组合好的越南语文字。设置向导会打开适合当前 macOS 版本的设置页面。PHTV Keyboard 的 Mac 版也需要权限来组合文字，并在 App 沙盒中运行。

PHTV 和 PHTV Keyboard 有什么区别？

两者共用输入引擎。直接下载的 PHTV 提供 GIF、贴纸和高级设置。PHTV Keyboard 面向 App Store，Mac 版提供快捷短语、剪贴板历史记录和表情符号，iPhone 和 iPad 版提供词语建议和滑动输入。Mac 上请一次只运行一种输入法。
