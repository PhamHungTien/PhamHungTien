用 vTTS 翻译 EPUB 电子书并离线收听

在 iPhone、iPad、Mac 或 Android 上用 vTTS 翻译 EPUB，另存译本，检查朗读语言和声音，并在下载语言包后离线收听。

Phạm Hùng Tiến 2026年11月23日 · 约 3 分钟阅读

本文目录

  1. 确认系统版本和语言组合
  2. 在 iPhone、iPad 或 Mac 上试译一章
  3. 在 Android 上翻译书籍
  4. 出门前试听译本

想用熟悉的语言听外文书，可以用 vTTS 翻译已导入的 EPUB。译本会单独存入书库，随时可以打开原文核对。在 Apple 设备上可先试译一章，在 Android 上可先用文字页面试译一小段。确认译文和朗读效果后，再处理整本书。

确认系统版本和语言组合

iPhone 和 iPad 上的翻译功能需要 iOS 或 iPadOS 18 及以上版本。Mac 上需要 macOS 15 及以上版本。可用的翻译组合取决于平台、源语言和目标语言。朗读语音已经随应用安装。Apple 系统可能在首次翻译时提示下载语言数据。Android 需要通过 Wi-Fi 下载所需资源。

可以先在文字页面粘贴一小段，例如 “The library opens at nine. Return the book by Friday.”，然后选择翻译文字。如果设备支持英语到中文，试着翻译这两句，再核对开馆时间和还书日期。短句更容易发现源语言选错的问题。还没导入 EPUB 时，可参考 vTTS 离线阅读指南。

在 iPhone、iPad 或 Mac 上试译一章

  1. 在书库中打开图书详情，等章节列表载入后，选择翻译书籍。
  2. 检查语言。原文语言明确时可以使用自动检测。篇幅很短或混用多种语言时，可手动选定源语言，然后从可用列表中选择目标语言。
  3. 如果书有多个章节，在从和到选择同一章。轻点翻译，按系统提示下载语言数据，并在处理期间保持 vTTS 打开。
  4. 翻译完成后，应用会另存一本书。选择打开书籍，检查目录。需要翻译全书时，可以回到原书，如果之前选过章节范围，可恢复为全部章节。

在 Android 上翻译书籍

  1. 进入图书阅读器，在工具栏选择翻译书籍。如果屏幕较窄，可在更多菜单中找到此操作。
  2. 在从和到设置源语言与目标语言。需要下载模型时，选择通过 Wi-Fi 下载。资源安装好后，界面会显示可离线使用。
  3. 等待翻译完成，检查结果，再轻点保存已翻译章节的按钮。回到书库打开译本。如果只想在 Android 上试译一小段，选择翻译文字并粘贴有权使用的内容。

出门前试听译本

播放第一段，对照原文检查标题、数字和人名。Apple 版会用目标语言打开译本。在两个平台上都可以检查阅读器中的朗读语言，并按需选择相应的声音。资源安装完成后，断开网络再试听一段，确认离线收听可用。

如果没有所需的目标语言，先检查源语言，再选择受支持的语言组合。译本占用一个书库名额。达到上限后，可以保留原书并删除不再需要的副本，也可以在应用内查看 vTTS Premium，以便保存更多书籍。

支持的翻译和语音生成在设备上进行。Android 使用 Google ML Kit，此 SDK 可能发送运行数据。有关数据处理和可选同步，请参阅 vTTS 隐私政策。要在其他播放器收听译本，可以参考 M4B 有声书导出指南。

vTTS 在英语、越南语及其他 15 种语言中挑选语音，可在 iPhone、iPad、Mac 和 Android 上收听。
