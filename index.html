  • PHTV

    Vietnamese input method for macOS

    PHTV is a free Vietnamese input method for macOS 14+ with Telex, VNI, text shortcuts, spell checking and clipboard history. For Apple Silicon and Intel Macs.

    macOS — Open source

  • vTTS

    Offline text to speech

    vTTS reads EPUB, PDF, DOCX and text aloud with built-in voices for 17 languages. Listen offline, change speed, set a sleep timer or export audio.

    iOS & iPadOS · macOS · Android — App Store, Google Play

  • Pad Code AI

    IDE for iPad and iPhone

    Pad Code AI is an IDE for iPad and iPhone that runs real Ubuntu Linux on the device: Python, C, C++, JavaScript, Go, Rust, Java and more, a terminal with apt, offline.

    iOS & iPadOS — App Store

  • Pad Notes AI

    Handwriting and PDF notes

    Pad Notes AI combines handwriting, PDF annotation, audio recording and memorization tape on iPhone, iPad and Mac. Start with up to 20 free notebooks.

    iOS & iPadOS · macOS — App Store

  • My NAS Manager

    Synology NAS manager

    My NAS Manager is a Synology DSM client for iPhone and iPad. Monitor CPU, memory and drive health, browse File Station and manage downloads.

    iOS & iPadOS — App Store

  • LunarV

    Vietnamese lunar calendar

    LunarV is a Vietnamese lunar calendar for iPhone, iPad, Mac and Apple Vision Pro. Convert dates, look up Can Chi and set lunar anniversary reminders.

  • Lunar Block
