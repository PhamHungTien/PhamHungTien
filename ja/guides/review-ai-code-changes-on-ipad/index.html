Pad Code AI

iPadでAIが書き換えたコードを差分で確認する方法

Pad Code AIの計画モードでJavaScriptの変更を考え、差分を確認します。iPadのWebプレビューで動作を試し、必要に応じて操作を元に戻します。

Phạm Hùng Tiến 2026年11月22日 · 約4分

この記事の内容

  1. 練習用のプロジェクトとモデルを用意する
  2. 計画を読んでからエージェントに編集を任せる
  3. ファイルごとの差分を確認し、ボタンを試す

Pad Code AIのエージェントに初めて編集を任せるなら、結果が目で分かる変更から始めましょう。ここでは読書チェックリストにリセットボタンを追加します。iPadやiPhoneで計画を立て、変更されたファイルを読み、操作を確かめるまでを行います。

練習用のプロジェクトとモデルを用意する

HTML・CSS・JavaScriptのプレビュー手順で作ったリストを開きます。自分のプロジェクトを使う場合は、練習用に複製しておくと確認しやすくなります。ファイルを保存し、プレビューで項目を1つ選んで 1 / 3 と表示されることを確認してください。

設定の AI アシスタント で使用するモデルを選びます。Apple Intelligenceを使うには、iOSまたはiPadOS 26以降の対応機種で機能を有効にします。Appleの対応機種と地域をご確認ください。ダウンロードモデルには空き容量とメモリが必要です。計画・編集・自動モードにはツール呼び出しに対応するモデルを選びます。オンラインのプロバイダを選ぶと、自分のAPIキーでメッセージと許可した情報が送信されます。エージェントが作業中に追加のプロジェクト情報を求めることもあります。送信前に共有内容を確認し、練習ではキーや個人情報を含まないファイルを使います。詳しくは プライバシーポリシー を参照してください。

計画を読んでからエージェントに編集を任せる

プロジェクトのAIパネルを開きます。既存コードの説明を聞くには 質問、ファイルを調べて修正方針を出してもらうには 計画 を使います。計画を選べない場合は、プロジェクトが開いているか、モデルがエージェントの操作に対応しているかを確認してください。

次のように、変更範囲と終了条件を伝えます。

リセットボタンの追加を計画してください。index.html にボタンを追加し、app.js にクリック時の処理を書いてください。押すと3つのチェックが外れ、完了数が 0 / 3 になります。既存の見た目と個別のチェック操作は保ってください。プレビューで使える標準のJavaScriptで実装します。

既存のチェックボックス一覧と updateProgress() を使う方針になっているか確認します。納得できたら 編集 に切り替え、実装を依頼します。編集モードではエージェントがプロジェクトのファイルを書き換えます。自動 では、対応するコードの実行まで許可されます。

ファイルごとの差分を確認し、ボタンを試す

  1. AIパネルの エージェントの変更 から直近の操作を開きます。画面が狭い場合は、パネルのメニュー内を探します。変更を確認 には、ファイルごとに追加行と削除行が表示されます。
  2. index.html にボタンが加わり、app.js にクリック処理があるかを読みます。処理は既存のチェックを外し、updateProgress() を呼び出す形なら追いかけやすくなります。予定外のファイルが変わっていたら、その操作の 操作を元に戻す を選び、対象を絞って頼み直します。
  3. index.html を ライブ Web プレビュー で開きます。開始時は 0 / 3、2項目を選ぶと 2 / 3、リセット後はすべて選択解除されて 0 / 3 になります。もう一度1項目だけ選べることも確認します。キーボードがあれば、Tabキーでボタンに移動し、Enterキーで実行します。

エージェントの変更は履歴を開く前にプロジェクトへ反映されます。最初は練習用のファイルで試し、Gitを使うプロジェクトではコミット前にソース管理画面でも差分を確認します。変更理由と動作確認の手順を自分の言葉で説明できれば、次の作業にも応用できます。

Pad Code AI Pad Code AIはUbuntu 26.04 LTSを端末上で動かします。サーバーもアカウントも不要。aptが使えるbashターミナル、一度ダウンロードすればオフラインで使える約60のツール、デバッガー、LaTeX、Gitを備えています。
