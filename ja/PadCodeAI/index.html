Pad Code AI iPad・iPhone向けIDE

iPadとiPhoneでプログラミングできる本物のUbuntu Linux

Pad Code AIはUbuntu 26.04 LTSを端末上で動かします。サーバーもアカウントも不要。aptが使えるbashターミナル、一度ダウンロードすればオフラインで使える約60のツール、デバッガー、LaTeX、Gitを備えています。

機能

  • 端末上で動く本物のUbuntu Linux

    arm64版Ubuntu 26.04 LTSがアプリ内で動作し、サーバーは不要です。各ターミナルタブはsudo apt installとUbuntuの全パッケージが使えるbashシェル。プロジェクトは/workspaceにあり、変更はすぐエディターに反映されます。

  • 約60のツールをオフラインで

    Python、Node.js、CとC++（gcc、Clang）、Java、Go、Rust、Ruby、PHP、.NET、Zig、Android SDK、マイコン向けツールチェーン、CMake、GDB、PostgreSQL、Redisなど。一度ダウンロードすればインターネットなしで使え、ファイルに必要なツールをアプリが提案します。pip install numpy pandas matplotlibもターミナル、スクリプト、ノートブックで使えます。Dockerも動作し、docker run、docker build、ポートの割り当てをターミナルで使えます。

  • 本物のツールによるデバッガーとコード補完

    Python、JavaScript、TypeScriptをデバッグ：条件付きブレークポイント、ログポイント、ステップ実行、変数、コールスタック、ウォッチ式、カーソルまで実行。Jedi、Clang、TypeScriptによる補完、BlackとPrettierによる整形に加え、定義への移動、名前変更、プロジェクト全体の検索と置換に対応します。

  • WebプレビューとLaTeX

    WebページはLinuxのWebサーバーから表示され、保存すると再読み込みされます。Webプロジェクトは開発サーバーを起動します。LaTeXはTeX Liveで本物のPDFに組版され、文書に必要な言語パッケージも自動でダウンロード。保存、共有、印刷ができます。iPadではプレビューがエディターの横に並び、入力に合わせて更新されます。iPhoneでは編集中も半分の高さで表示しておけます。

  • Vibe Coding

    変更内容を言葉で伝えます。「質問」「計画」「編集」「自動」から任せる範囲を選択。「自動」ではアシスタントがLinuxでコマンドやテストを実行します。コマンドライン型のコーディングエージェントも専用のターミナルタブで開き、ご自身のアカウントで利用できます。

  • AIの動作環境を選ぶ

    対応端末・地域で使えるApple Intelligenceや、メモリに余裕があればQwen、Gemmaなどのモデルをダウンロードしてオフラインで使えます。オンラインのプロバイダにはご自身のAPIキーとネット接続が必要です。

  • Git、SSH、SFTP

    GitHub、GitLab、BitbucketからHTTPSでクローン。差分の確認、コミット、ブランチ作成、stash、push、pullができ、GitHubにサインインすれば非公開リポジトリも開けます。vim、htop、tmuxが動くフルカラーのSSHターミナルと、サーバー上のファイルを参照・編集するSFTPにも対応。

  • 無料ツールとオプションのPro

    編集、対応言語のコード実行、Git、Webプレビューは無料です。分割エディターやプロジェクト全体の置換などのPro機能には毎日の無料利用枠があります。選べるアップグレードはアプリ内で確認できます。

よくある質問

オフラインでコードを実行できますか？

はい。Linuxと必要なツールを一度ダウンロードすれば、コードの実行、ターミナル、デバッガー、LaTeXは接続なしで使えます。追加パッケージのダウンロード、SSHサーバーへの接続、リモートGitの取得、オンラインAIの利用には接続が必要です。

Linuxの容量はどれくらいですか？

最初のダウンロード（LinuxとPython）は約310 MBです。その他のツールは選んだときだけダウンロードされ、設定 › Run & Terminalからいつでも削除できます。実行環境を内蔵しないため、アプリ本体は軽量です。

GitHubの非公開リポジトリは開けますか？

アプリでGitHubにサインインすると、アカウントがアクセスできるリポジトリを参照してクローンできます。クローン後は端末上で差分の確認やコミットができます。
