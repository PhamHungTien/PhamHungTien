利用規約

最終更新 2026年11月22日

1. 規約への同意

Pad Code AI（以下「本アプリ」）をダウンロード、インストール、または使用すると、本利用規約に同意したことになります。同意しない場合は本アプリを使用しないでください。

2. サービスの説明

Pad Code AIはiPadとiPhone向けのコードエディター・統合開発環境です。ソースコードの作成、編集、実行、管理を行えます。端末上で動作する言語の実行環境、ターミナル、Git、対応バージョンでのSSHとSFTP、オプションのAIコーディングアシスタントを備えています。

オプションの有料機能

基本の編集、対応するローカルコードの実行、Webプレビュー、Git、読み込みと書き出し、単一ファイル内の置換は、購入なしで利用できます。提供される場合、Pad Code AI Proは買い切り、自動更新される月額または年額のサブスクリプションとして提供されることがあります。確認前に、利用できる機能、価格、請求期間、トライアルの有無をApp Storeに表示します。サブスクリプションはApple Accountの設定で管理でき、対象の購入は購入時のApple Accountを使ってアプリで復元できます。返金または取り消しがあった購入による利用資格は失効します。以前に付与または購入された利用資格には、当時の条件が適用されます。第三者のAIサービス料金は別途かかります。Appleのサブスクリプションと請求

3. 利用者のコンテンツ

本アプリで作成、編集、閲覧、クローン、実行するソースコード、ファイル、プロジェクトに関する権利は、すべて利用者に留保されます。開発者が利用者のコンテンツについて所有権を主張することはありません。

本アプリで作成、実行、クローン、pushするコードについては、利用者が責任を負います。

4. 端末上でのコード実行

プログラムは、コーディング、学習、テストのため、端末上のサンドボックスで実行されます。サンドボックスからシステム全体にアクセスすることはできません。Pythonコードの実行時に、パッケージサービスから追加のパッケージや依存関係をダウンロードすることがあります。Webプレビューのコンテンツは、コード内で参照している外部サービスに接続する場合があります。ソースコードをコンパイルや実行用のサーバーにアップロードすることはありません。アプリの応答性を保つため、実行時間、メモリ、出力には上限があります。

5. AIアシスタント

オプションのAIアシスタントは、端末とApp Storeの地域での利用可否に応じて、対応する端末上のモデル、またはご自身のAPIキーで設定した第三者プロバイダを利用できます。第三者プロバイダを利用する場合は、以下が適用されます。

  • プロバイダの規約とプライバシーポリシーにも従うものとします。
  • APIキーの管理と、プロバイダから請求される利用料金は利用者の責任です。

AIの提案は現状有姿で提供されます。使用前にご確認ください。AI生成コードの正確性や用途への適合性について、開発者は責任を負いません。

6. Gitとネットワーク機能

Gitのclone、fetch、pull、pushは、GitHubを含む、選択した対応HTTPSリポジトリホストと通信します。認証にはホスト用のアクセストークンが必要な場合があります。以下は利用者の責任です。

  • クローンするリポジトリとpushするコード。
  • リポジトリのアクセストークンの保護。
  • 利用する第三者プラットフォームの規約の遵守。

SSHやSFTPでは、アクセスを許可されたシステムにのみ接続してください。サインイン情報の保護、サーバーの身元の確認、コマンド、ファイル転送、サーバー上での編集の確認は利用者の責任です。サーバー運営者の規約が適用されます。

7. オープンソース構成要素

本アプリには、LLVM/Clang、CPython（Pyodide）、Ruby、PHP、Lua、TypeScriptなどのオープンソースソフトウェアが含まれます。ライセンスはアプリの設定から「情報 → オープンソースライセンス」で確認できます。本アプリ自体はプロプライエタリソフトウェアです。

Pad Code AIは、いかなる保証もなく現状有姿で提供されます。適用法令が認める最大限の範囲で、開発者は、データの損失、コード実行のエラー、Git操作の失敗など、本アプリの利用から生じた損害について責任を負いません。

9. 規約の変更

本規約は更新される場合があります。変更後に本アプリの使用を続けると、更新された規約に同意したことになります。
