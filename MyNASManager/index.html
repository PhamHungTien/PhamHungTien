My NAS Manager

Synology NAS client

Manage Synology NAS from your Apple devices.

System monitoring, File Station, and SSH in one app.

Download on the App Store Privacy
Platforms
iOS & iPadOS, macOS
Server
Synology DSM 7+
Tools
Files + SSH + Packages

Features

  • Seven languages & demo mode

    Supports Vietnamese, English, German, Spanish, French, Japanese, and Simplified Chinese. Explore the interface with simulated data before connecting a NAS.

  • Realtime monitoring

    Watch CPU, memory, temperature, network, and drive health.

  • Mobile File Station

    Browse, upload, download, and create share links from iPhone, iPad, or Mac.

  • SSH management & terminal simulator

    Toggle SSH services, change ports, and execute basic commands such as ls, df, top, and uptime through the terminal simulator.
